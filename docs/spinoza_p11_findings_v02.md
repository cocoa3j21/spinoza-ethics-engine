# スピノザ『エチカ』第1部 命題11周辺形式化モデルにおける知見整理 (v0.2)

本報告書は、スピノザ『エチカ』第1部形式化データ（v0.2正式候補版: [`data/spinoza_ethics_part1_split_prop6.json`](../data/spinoza_ethics_part1_split_prop6.json)）および各種感度実験に基づき、命題11周辺の論理構造に関して得られたモデル内の結果を整理したものである。

> [!IMPORTANT]
> **学術的位置づけと前提条件に関する注意事項**:
> - 本書に記載された結果は「新発見」ではなく、**「定義された形式化モデル内での論理的計算・グラフ探索結果（モデル内の結果）」**です。
> - これらの論理的帰結に関する哲学研究上の学術的新規性（先行するスピノザ解釈史や文献学的な新規性）は**未確認**です。
> - 記載の数値・件数は、特記なき限り**「設定(a)・DEF_6補完あり」**における値です。モデル化の範囲（全26項目(定義8、公理7、命題11)体系か縮約パイロットか）や解釈設定によって件数や成否は変動します。

## 1. 知見の分類一覧表

モデル内の結果を、「安定した知見」「解釈に依存する知見」、および「手法の性質（エンジンの前提）」の3つに明確に分類して示す。

### 1.1 手法の性質（推論エンジンの前提条件）

※ スピノザの論証内容から導かれた結果ではなく、**計算意味論（エンジン）の設計と公理的性質に由来する前提条件**です。

| 項目 | 性質の説明 | 根拠となるエンジンの仕様 | 位置づけ |
| :--- | :--- | :--- | :--- |
| **真理値遷移の非対称性 (否定支持の非発生)** | 前提や規則が遮断されて支持を失った命題は常に `UNKNOWN` となり、否定支持（`FALSE`）は生じない。スピノザ体系の幾何学的証明構造において、前提の遮断は結論の「偽」を帰結させるのではなく「無証（不可知）」をもたらす。 | 単調性・診断的意味論（diagnostic_monotone）の公理的性質 | **スピノザの論証についての結果ではなく、エンジンの意味論の性質** |

### 1.2 安定した知見（登録済みモデル・設定で頑健に成立する結果）

| 知見（モデル内の結果） | 概要・詳細な数値 | 根拠となるモデル・設定 | 原典の該当箇所 |
| :--- | :--- | :--- | :--- |
| **命題2・3・公理5の迂回可能性** | 命題6の系の別証明（または全別証明統合）を導入した場合、公理4等により、命題2・命題3・公理5を経由しない証明経路が存在する。<br>*(※「迂回経路の存在」は、さらに証明を追加しても崩れることはありません)* | **モデルC1, C2**（別証明1の設定a〜dすべてで迂回成立） | *Ethica I, Prop. 6, Corollarium, Demonstratio aliter*<br>*Ethica I, Prop. 11, Aliter* |
| **命題6本文導出の迂回可能性** | 命題6本文の導出に必要な前提は **7件** (`AX_1, AX_4, AX_5, AX_6, DEF_3, DEF_4, DEF_5`) であるが、系の別証明が使う前提は **`DEF_3` と `AX_4` の2件** のみであり命題6本文を引用しない。そのため、系別証明を採用したモデルでは命題6本文を迂回し、C1での命題11全体は **5前提** (DEF_6補完あり: `AX_4, AX_7, DEF_1, DEF_3, DEF_6`) で成立する。 | **モデルC1, C2** | *Ethica I, Prop. 6, Corollarium, Demonstratio aliter* |
| **DEF_3の必須性 (登録済み3ルートの範囲)** | 登録済みの3ルート（第1証明、系の別証明、別証明1）の範囲において、報告された全モデル・全設定で共通前提かつ単体遮断となる。<br>*(※命題11の第3証明は未登録のため、全証明で必須とは言えません)* | **全モデル (A, B, C1, C2)**<br>および全設定 (a〜d)<br>※登録済み3ルート内 | *Ethica I, Def. 3*<br>(Prop. 2, 6系, 11別証明で引用) |

> [!NOTE]
> **「迂回経路の存在」と「単体遮断・共通前提」の論理的非対称性**:
> - **迂回経路の存在**: 新たな別証明や経路を追加しても、既存の迂回経路が消えることはありません（単調性により維持される）。
> - **単体遮断・共通前提**: 新たな別証明を追加すると、その新しい経路によってこれまで必須だった前提や規則が迂回可能となり、**単体遮断や共通前提は弱まり（減少し）えます**。したがって、未登録の「命題11第3証明（*Aliter 2*）」を追加した場合、`DEF_3` を含む共通前提や単体遮断がさらに変化する可能性があります。

## 2. 正式データ (v0.2 候補) と検証用パイロットデータの位置づけ

1. **正式データ候補 (`data/spinoza_ethics_part1_split_prop6.json`)**:
   - 第1部26命題体系全体を網羅。
   - `PROP_5` の依存を原典通り `PROP_4, PROP_1, DEF_3, AX_6` に修正（`DEF_6` 除外、`AX_6` 追加）。
   - 命題6本文（`PROP_6`）と系（`PROP_6_COROLLARY`）を独立ノード化。系の第1証明（`PROP_6, AX_1, DEF_3, DEF_5`）、系の別証明（`DEF_3, AX_4`）、命題7（系と `DEF_1`）を原典本文に完全準拠させて配線。
2. **検証用パイロットデータ (`data/spinoza_pilot_v2.json` 等)**:
   - 命題11周辺の主要12〜13項目を抽出・縮約した高速検証用サブセット。
   - 縮約に伴い `PROP_5` 等に概念的補完（`DEF_6`）が含まれるため、縮約モデル特有の挙動（系別証明がない場合に `PROP_5` 経由で `DEF_6` が残存するなど）が生じる。

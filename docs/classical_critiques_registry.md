# 古典的批判台帳（Classical Critiques Registry）

> [!IMPORTANT]
> **【本台帳の位置づけと運用方針】**
> 本台帳は、神の存在論証に対する古典的な批判（ガウニロ、アクィナス、カント）について、論証グラフの**どの前提または推論規則に向けられるか**、**典拠・出典（章・節・標準頁）**、**状態の3段階表記**、および**解釈の確度と留保事項**を整理した準備資料です。
> **本台帳の批判ルールは、推論コア・既存データ（自動演繹・ベンチマーク）には組み込んでいません。**
> 用語は「**批判が向けられる前提**」で統一しています。

## 2. 各批判の詳細と哲学的分析

### (1) ガウニロの批判（Guanilo: *Pro Insipiente*）
* **論点1: 失われた島のパロディ（Cap. 6、AI照合済み(人の確認前)）**
  - **内容**: 「至福の島」の概念から客観的実在が導かれるならば背理である。同型の推論規則が破綻しているため、論理形式そのものが退けられる。
  - **実装**: `R_ANS1_C` の遮断（解釈B）。
* **論点2: 言葉の上の理解（Capp. 2, 4、AI照合済み(人の確認前)）**
  - **内容**: 愚者は「神」という音声（*secundum vocem*）を聞いているにすぎず、実質的な心内観念（*in intellectu*）を把握していない。
  - **実装**: `ANS1_P2` の遮断（解釈A）。

### (2) トマス・アクィナスの批判（Aquinas: *Summa Theologiae* Ia, q. 2, a. 1）
* **批判の核心**:
  - **ad 2（AI照合済み(人の確認前)）**: 「すべての人が神を『それより大なるものが考えられないもの』と理解しているわけではない。たとえ理解しても、それが客観的実在（*in rerum natura*）にあると理解するわけではなく、知性の了解作用の内部（*in apprehensione intellectus tantum*）にあるにすぎない」。
  - **resp.（AI照合済み(人の確認前)）**: 「それ自体自明（*per se notum in se*）」と「われわれにとって自明（*per se notum quoad nos*）」の厳密な区別。神の本質を直観できない人間知性にとって神の存在は先天的自明ではない。
  - **本線**: 推論段階の遮断（`R_ANS1_C`, `R_ANS2_C` / 解釈B、直接対応）。
  - **候補**: 定義了解の拒絶（`ANS1_P1`, `ANS2_P1` / 解釈A、候補）。
* **デカルトへの当てはめ（カテルス『第一反論』AT VII 98-99、AI照合済み(人の確認前)）**:
  - 第一反論の神学者カテルスがアクィナスの上記 `ad 2` を直接引用し、デカルト第五省察の存在論証を批判。「概念から実在へは跳躍できない」。
  - 幾何学的証明公理 `DES_AX_10` への適用は、このカテルスの論点を幾何学的定式化に当てはめた解釈的対応。

### (3) イマヌエル・カントの批判（Kant: *Kritik der reinen Vernunft*）
* **批判の核心**:
  - 「存在は実在的述語ではない（*Sein ist offenbar kein reales Prädikat*）」（A598/B626）。
  - 百タレルの比喩（**A599/B627、AI照合済み(人の確認前)**）: 概念に存在を付け加えても概念内容は増加しない。存在は概念の位置づけ（繋辞）である。
  - **デカルト命題1**: `DES_AX_10` の遮断（直接対応）。
  - **アンセルムス論証1**: `ANS1_P3` の遮断（解釈的対応）。
  - **アンセルムス論証2**: `ANS2_P2` の遮断（候補・要確認 / 様相論証解釈による対立あり）。
  - **スピノザ定義1**: `DEF_1` の遮断（解釈的対応(研究文献による) / AI記載、未照合 / Omri Boehm 2014 等の二次文献に基づく比較）。
    - **Basile (2010) の二面的評価**:
      1. カントやラッセルの批判はスピノザの証明の的を外している。
      2. 一方、スピノザの証明を複数の読み方で評価した結果、どの読み方でも無効または論点先取であると結論づける。

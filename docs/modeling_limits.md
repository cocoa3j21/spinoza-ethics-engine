# 幾何学的哲学推論エンジン モデリングの限界と原典留保事項 (docs/modeling_limits.md)

**版数**: 2.0 (v0.1 Standard Freeze: Theoretical Distinctions & Philological Reservations)  
**更新日**: 2026-10-21  

---

## 1. 本エンジンの目的と位置づけ

本システムは、哲学思想の正しさや哲学者の勝敗を審判するものではありません。
その目的は、**「テキストに明示された公理・定義からどの定理がいかなる推論規則によって導出され、特定の前提変更や批判によってその支持関係がどのように変化するか」を、客観的かつ再現可能に追跡すること**にあります。

## 2. 形式論理モデルとしての適用範囲と限界

### (1) 現在の対応範囲
* **有限の符号付き命題規則 (Signed Propositional Rules)**:
  * 有限個の命題記号に対する正・負のリテラルと、論理積（AND）前提から単一結論を導くホーン節形式の有向規則。
* **二重批判モデル (Rebutting Conflict & Undercutting Defeat)**:
  * 命題同士の両立不能な衝突（ConflictPair: 診断専用）と、推論規則の妥当性を無効化する批判（UndercutDefeater）の明確な区別。
* **有向非巡回グラフ (DAG) 制約**:
  * 推論規則の証明チェーンは厳密なDAGを構成し、循環論証は構文段階で排除される。

### (2) 現在のモデルが扱えない範囲（設計上の非対応事項）
1. **様相論理 (Modal Logic - 必然性と可能性)**:
   * スピノザの「必然的実在（Necessario existit）」やライプニッツの「可能世界論（Possible Worlds）」は単一の命題識別子として扱われており、Kripke意味論（可能世界アクセス可能性）によるモダリティの体系的計算は行っていない。
2. **述語論理・高階論理の完全な量化**:
   * 論理式文字列（`logical_form`）は人間可読な注記であり、一階述語論理の全称記号（$\forall$）や存在記号（$\exists$）の自動単一化（Unification）や自動定理証明（ATP）は実行していない。
3. **弁証法・動的語彙変容 (Dialectics)**:
   * ヘーゲル弁証法のような、対立（テーゼとアンチテーゼ）の止揚（ジンテーゼ）によって概念自体の意味が変容する動的意味論には対応していない。
4. **暗黙の対偶推論と爆発律の非導入**:
   * 準無矛盾論理（Paraconsistent Logic）の精神に基づき、暗黙の対偶推論（$P \to Q$ から自動的に $\neg Q \to \neg P$ を生成すること）や爆発律（無矛盾律違反から任意の命題を導くこと）を意図的に導入していない。

### (3) 停止性と不動点に関する理論的厳密化

推論エンジンの停止性、閉路検出、および論証理論の適用にあたっては、以下の理論的区別を厳格に保持する：

1. **辺数偶奇と負辺数偶奇の峻別**:
   * 「奇数長負閉路」という曖昧な表現を排し、閉路を構成する**「辺数（エッジ長 / path length）の偶奇」**と、閉路に含まれる批判・衝突等の**「負辺数（negative edge count）の偶奇（パリティ）」**を厳密に区別する。
   * 非単調な議論の振動・非収束において本質的なのは辺数ではなく、「奇数個の負辺を持つ閉路（負辺数のパリティが奇数）」である。
2. **総合DAG制約と層化条件（Stratification）の区別**:
   * 規則・批判・衝突を合わせたグラフ全体が非巡回である「総合DAG制約」と、論理プログラミング等の「層化条件」を同義としてはならない。
   * 総合DAG制約は正負すべての依存の閉路を禁じる極めて強い十分条件であり、層化条件は否定・攻撃を跨ぐ閉路のみを禁じ、同一層内の正の証明依存は許容する。
3. **Stable Extension（安定拡大）の存在性**:
   * 奇数個の負辺を持つ閉路が存在する場合でも、外部からの優勢な攻撃（未反論の攻撃者による閉路内ノードの確定的な敗北）が存在する場合など、Dung の Stable Extension が存在し得る場合がある。
   * したがって、「奇数攻撃閉路が存在する $\implies$ Stable Extension 不存在」と断定してはならない。
4. **独自撤回方式と Dung 意味論の未定義性**:
   * 実験モード（EXPERIMENTAL）等で実装された真理維持機構（Truth Maintenance / 動的撤回）と、Dung の抽象論証意味論（Ground/Preferred/Stable等）との厳密な数学的対応関係は「未定義（Undefined）」である。
5. **停止状態と正当化検証結果の区別**:
   * ワークリストアルゴリズムが終了した「停止状態（`status=CONVERGED`）」と、現在蓄積された支持が正当な証明経路によって完全に支えられているかという「正当化の十全性検証（`justification_validation`）」を区別する。
   * 旧方式（LEGACY）のように、幽霊的正当化（撤回されない衝突否定支持）によって擬似的に停止状態に達したとしても、正当化が不全である状態を客観的に検出・分離する。
6. **v0.1 標準意味論 (`diagnostic_monotone`) による停止性の完全保証**:
   * v0.1 標準意味論では、肯定・否定の支持が単調蓄積され、ConflictPair は診断専用（推論途中の真理値変更なし）、Undercut は事前確定であるため、作用素は有限完備束上の単調写像となる。
   * Knaster–Tarski 定理により、有限ステップで一意な最小不動点へ到達し、入力によらず**100%確実に停止することが数学的に保証**される。

## 3. 哲学データに関する原典留保事項

### (1) イマヌエル・カント『純粋理性批判』
* **存在論的証明批判の射程**:
  * カントの批判（「存在は実在的述語ではない」A598/B626）は、「神は存在しない」という無神論的主張ではありません。
  * 本エンジンでは、この批判を神の存在否定命題（$\neg GodExists$）ではなく、**「概念の分析から客観的実在性を導出する推論規則の無効化（Undercutting Defeater）」**としてモデル化しています。
* **物自体の認識制限**:
  * 「現象と物自体の限界公理」は、物自体の不存在を主張するものではなく、**「理論理性による超越的実体の客観的認識規則の無効化」**としてモデル化しています。

### (2) バールーフ・デ・スピノザ『エチカ』第1部
* **命題1〜6の残存とカント批判の限定性**:
  * 耐震性ベンチマークにおいてスピノザの命題1〜6（実体の先理性、異属性実体の無共通性、因果否定、区別原理、同属性実体単一性、他者産出不能性）が残存したのは、**「本モデルにおいて、カントの批判公理（存在論的証明批判 KANT_AX_1）の無効化対象を命題7（自己原因による存在証明）に限定して定義したことの形式的帰結」**にすぎません。
  * これを、カント『純粋理性批判』超越論的弁証論における純粋理性の誤謬推理やアンチノミー批判、物自体と現象の区別がスピノザの実体・属性論全体に対して投げかける根本的な批判に対する「普遍的耐性」と説明してはなりません。
* **命題11の複数証明（別証明）**:
  * 原典において、スピノザは神の必然的実在（命題11）に対して複数の異なる論証を与えています。現在のデータセットは第1証明を中心にモデル化していますが、充足理由律からの別証明などを別個の推論規則として拡充することで、存在論的証明批判に対する耐震性の精密な再評価が可能となります。

### (3) ルネ・デカルト『省察』『幾何学的順序による論証』
* **第三省察の神の存在論証と第六省察の物体存在証明の峻別**:
  * デカルトの物質的物体の実在性証明（`DESC_PROP_4`）は『省察』第**六**省察（AT VII, 71-80）における議論であり、「感覚の受動性」および「神が欺くものではないこと（神の誠実さ）」を前提とします。
  * 一方、カントが批判した存在論的証明（完全性の概念から存在を分析的に導く論証）は第**五**省察（AT VII, 63-71）であり、無限の観念の客観的実在性に基づく神の存在論証は第**三**省察（AT VII, 34-52）です。
  * 第六省察の物体存在証明は、第五省察の存在論的証明に直接依存しているのではなく、神の誠実さを通じて第三省察の神の存在論証に依存しています。
  * したがって、カントの存在論的証明批判（KANT_AX_1）単独では第三省察ルートは無効化されず、感性直観の認識制限批判（KANT_AX_3）が合流して初めて物体存在証明の根拠が崩壊するというのが、形式モデルの正確な帰結です。

### (4) ゴットフリート・ライプニッツ『モナドロジー』
* **批判対象にしなかった命題と選定理由**:
  * 本モデルにおいてカント批判の対象としたのは、最善世界の選択・予定調和（`LEIB_PROP_2`）に対する物自体の認識制限（`KANT_AX_3`）のみです。
  * 批判対象にしなかった命題群：
    * `LEIB_DEF_1`, `LEIB_PROP_1`: 単子の単純性、窓なきモナド
    * `LEIB_AX_1`: 矛盾律、`LEIB_AX_2`: 充足理由律、`LEIB_AX_3`: 不可識別者同一の原理
    * `LEIB_PROP_3`: 物質の現象性（実体性の否定・整序された現象）
  * **選定理由と学術的留保**:
    * ライプニッツ自身が物質を究極的実体と認めず「整序された現象（phaenomenon bene fundatum）」と定義していた点において、カントの現象論的批判との形式的親和性を検証するためにこれらを非対象としました。
    * しかし、非物質的実体（モナド）そのものの実在論証（充足理由律からの必然的存在の要請）や不可識別者同一の原理は、カントの『反省概念の多義性について』（純粋理性批判 A260/B316以下）において直接的かつ徹底的な批判の対象となっています。本モデルではこれらの批判公理をデータセットに組み込んでいないため残存したにすぎず、ライプニッツ体系全体がカント批判に対して無条件に強靭であることを意味するものではありません。

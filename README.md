# Philosophy Geometric Engine (幾何学的哲学推論エンジン)

**バージョン**: v0.2 (Spinoza Ethics Part 1 Proposition 11 Formalization & Sensitivity Analysis)  
**動作環境**: Python 3.10+ (3.14 動作確認済) / **外部依存ゼロ**（標準ライブラリのみで動作）

幾何学的な「公理」「定義」「定理」に基づき、原典の演繹構造、別証明による迂回経路、反論（Conflict）、および批判（Undercutting Defeat）を客観的・再現可能に分析するための形式推論エンジンです。

哲学者の優劣や勝敗を決めることではなく、**「原典に基づく議論の支持関係と、前提変更の影響を再現可能に追跡すること」**を目的としています。

---

## 📖 プロジェクトの目的

スピノザ『エチカ』第1部「神について」における幾何学的演繹（*ordo geometricus*）は、公理・定義から出発し、命題11（神の必然的存在証明）に至る強固な論理体系として知られています。しかし、原典中には複数の証明経路（系、別証明など）が存在し、どの前提がどの結論にとって真に不可欠であるか、また特定の前提を外した際にどの経路が生残するかは、直観のみでは正確に把握できません。

本プロジェクトは以下を目的としています：
1. **客観的な演繹グラフの構築**: 原典ラテン語の記述と明示的引用を厳密に対照し、形式論理的な依存グラフを構築する。
2. **別証明・迂回経路の定量的解明**: 複数証明の論理和的関係（独立支持モデル）を形式化し、命題11に至る迂回可能性を明らかにする。
3. **反実仮想・感度分析の再現性**: 前提の無効化（単体遮断・最小前提集合探索）を通じて、議論の耐震性を数学的に検証する。

## 🔬 v0.2 の主要結論 (Proposition 11 Analysis)

スピノザ『エチカ』第1部 命題11（神の必然的存在）を中心とする形式化体系（正式候補データ: [`data/spinoza_ethics_part1_split_prop6.json`](data/spinoza_ethics_part1_split_prop6.json)）において得られた計算結果は、以下の3つに分類されます。

### 1. 安定した知見 (モデルや解釈によらず一貫して成立する結果)
- **定義3（実体）の必須性**:
  - 登録済みの3ルート（第1証明、系の別証明、別証明1）の範囲において、報告された全モデル・全感度設定で**共通前提かつ単体遮断**（定義3を遮断すると命題11は不成立）。
- **命題2・3・公理5の迂回可能性**:
  - 複数証明を統合したモデル（C1: 系の別証明併用、C2: 別証明1併用）において、別証明1の解釈設定(a)〜(d)すべてで**命題2、命題3、公理5は迂回可能**となる（※この全設定での迂回成立はモデルC1・C2に限定され、モデルBでは命題2は全設定で迂回不可、命題3・公理5は設定cのみ迂回可能）。
  - これは原典において「命題6の系の別証明」が命題6本文（およびそれに先行する命題2・3）を経由せず、定義3と公理4のみから直接系を導出することに起因する。
- **モデルB（別証明なし・系のみ）における迂回可否**:
  - 命題2は全設定で迂回不可。
  - 命題3と公理5は、別証明1の解釈(c)（命題7を公理展開する設定）においてのみ迂回可能。
- **補完前提（DEF_6: 神の定義）の影響**:
  - 第1証明においてDEF_6を補完前提として残す場合、第1証明単独時の全10前提が単体遮断となる。DEF_6を外した場合は9前提。
  - C1およびC2では、別証明1がDEF_6を使用しないため、DEF_6は共通前提および単体遮断から外れる。

### 2. 解釈に依存する知見 (別証明1の形式化解釈に依存する結果)
- **共通前提数の変動**:
  - 命題11 別証明1の解釈4設定（(a) 現行設定、(b) 命題7除外、(c) 命題7展開、(d) 完全展開）によって、モデルC2の共通前提数は2件（設定a, b: DEF_3, AX_4）から4件（設定c, d: DEF_3, AX_4, DEF_5, AX_1）へと変動する。
- **定義1（自己原因）からの独立性**:
  - 別証明1が命題7を含まない設定 (a), (c) でのみ成立し、命題7を含む設定 (b), (d) では定義1が必要となる。

### 3. 手法の性質 (推論エンジンの意味論的前提)
- **否定支持の非発生**:
  - 命題11に対して否定支持（$b_-$）が発生しないことは、**スピノザの論証に関する結果ではなく、本推論エンジンの意味論の性質**である。前件否定の誤謬を根絶するため、前提が不足しても結論の否定を生成せず「不発」とする設計に基づいている。

## ⚠️ 限界・留保事項

- **学術的新規性の未確認**:
  - 本報告の知見は「本推論モデル内での計算結果」であり、既存のスピノザ文献学や哲学史研究における学術的新規性・定説適合性は未確認です。
- **未登録証明の影響**:
  - 命題11には第3証明（背理法・有限存在と無限存在の力に基づく論証）が存在しますが、現行データには未登録です。そのため、「定義3があらゆる証明において必須である」と一般化して断定することはできません。
  - 「迂回経路の存在」は新たな証明を追加しても崩れませんが、「単体遮断」や「共通前提」は別証明の追加によって弱まりうる性質を持ちます。
- **離散形式化の抽象化限界**:
  - 原典の豊かなラテン語自然言語テキストを命題論理的DAG（有向非巡回グラフ）へ変換しているため、テキスト解釈の多義性や文脈的ニュアンスの捨象を伴います。

## 🌟 主な特徴 & 形式意味論

1. **2ビット独立支持モデル**:
   - 各命題の状態を肯定支持ビット $b_+$ と否定支持ビット $b_-$ の直積として表現：
     - `00`: **`UNKNOWN`** (未証明・未支持)
     - `10`: **`TRUE`** (肯定支持のみ成立)
     - `01`: **`FALSE`** (否定支持のみ成立)
     - `11`: **`CONFLICT`** (肯定・否定の双方が支持された二律背反)
   - **前件否定の誤謬の根絶**: 前提不足は規則を「不発」にするのみで、結論の否定支持を自動生成しません。
   - **複数証明（別証明）の論理和的許容**: 一方の証明経路が遮断されても、別の独立した証明規則が残存していれば肯定支持が維持されます。

2. **v0.1/v0.2 共通推論意味論 (`diagnostic_monotone`)**:
   - **完全単調蓄積**: 推論途中で支持の撤回・消去を行いません。
   - **停止性の数学的保証**: 有限完備束上の単調写像となるため、Knaster–Tarski 定理により、いかなる入力に対しても有限ステップで一意な最小不動点へ確実に停止します。

## 🧩 他体系データを必要とするモジュールについて

本リポジトリは、スピノザ『エチカ』第1部の幾何学的論証に特化した**単独公開パッケージ**です。  
推論エンジン内には哲学体系間の比較や批判シナリオを扱う以下のモジュールが含まれていますが、これらは他体系データ（デカルト、ライプニッツ、カント批判等）を必要とするため、本単独版では機能が制限・非表示となります：

1. **`engine/benchmark_core.py` (`PhilosophicalBenchmark`)**:
   - デカルト、スピノザ、ライプニッツの3体系に対し、カントの存在論的証明批判シナリオを適用して定理生存率を比較するモジュール。
2. **`engine/insights_generator.py` (`InsightsGenerator`)**:
   - カント批判シナリオにおける各体系の耐震性カードを自動生成するモジュール（Web UIの「今回わかったこと」タブ）。
3. **`engine/comparative.py`**:
   - 複数体系間の概念・定理比較モジュール。

> **動作・テスト上の扱い**:  
> 本パッケージの Web UI では、他体系データを要求するタブ（「今回わかったこと」「耐震性ベンチマーク」）は非表示となっており、自律稼働する「幾何学グラフ」および「研究成果（命題11感度分析）」のみが提供されます。また、テストスイートにおける該当ベンチマークテスト（`test_07_benchmark_output_includes_required_metadata`）は明示的にスキップ（`skipped=1`）され、Spinoza 単独テスト全49件は外部依存なしに完全 PASS します。

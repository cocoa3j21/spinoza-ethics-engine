幾何学的な「公理」「定義」「命題」に基づき、原典の演繹構造、別証明による迂回経路、反論（Conflict）、および批判（Undercutting Defeat）を原典と対照しながら再現可能に分析するための形式推論エンジンです。

哲学者の優劣や勝敗を決めることではなく、**「原典に基づく議論の支持関係と、前提変更の影響を再現可能に追跡すること」**を目的としています。

## 📖 プロジェクトの目的

スピノザ『エチカ』第1部「神について」（定義8、公理7、命題1〜8、11、14、15の計26項目、および系1項目を含む計27項目）における幾何学的演繹（*ordo geometricus*）は、公理・定義から出発し、命題11（神の必然的存在証明）に至る強固な論理体系として知られています。しかし、原典中には複数の証明経路（系、別証明など）が存在し、どの前提がどの結論にとって真に不可欠であるか、また特定の前提を外した際にどの経路が生残するかは、直観のみでは正確に把握できません。

本プロジェクトは以下を目的としています：
1. **原典と対照した演繹グラフの構築**: 原典ラテン語の記述と明示的引用を対照し、形式論理的な依存グラフを構築する。
2. **別証明・迂回経路の定量的解明**: 複数証明の論理和的関係（独立支持モデル）を形式化し、命題11に至る迂回可能性を明らかにする。
3. **反実仮想・感度分析の再現性**: 前提の無効化（単体遮断・最小前提集合探索）を通じて、議論の依存関係を数学的に検証する。

## ⚠️ 限界・留保事項

- **学術的新規性の未確認**:
  - 本報告の知見は「本推論モデル内での計算結果」であり、既存のスピノザ文献学や哲学史研究における学術的新規性・定説適合性は未確認です。
- **暗黙の充足理由律依存**:
  - このモデルは、本文の明示引用と、モデル作成者が採用した補完前提を区別して登録しています。原典に含まれる暗黙の依存を、すべて網羅したものではありません。各証明が充足理由律に暗黙に依存すると読む研究がある。その読み方では、充足理由律のみを遮断した結果は変わりうる。
- **未登録証明の影響**:
  - 命題11には第3証明（背理法・有限存在と無限存在の力に基づく論証）が存在しますが、現行データには未登録です。そのため、「定義3があらゆる証明において必須である」と一般化して断定することはできません。
  - 「迂回経路の存在」は新たな証明を追加しても崩れませんが、「単体遮断」や「共通前提」は別証明の追加によって弱まりうる性質を持ちます。
- **離散形式化の抽象化限界**:
  - 原典のラテン語自然言語テキストを命題論理的DAG（有向非巡回グラフ）へ変換しているため、テキスト解釈の多義性や文脈的ニュアンスの捨象を伴います。
- **論理的枠組みの理論的由来**:
  - なお、本推論エンジンの2ビットの支持状態（肯定支持と否定支持の組み合わせによる未証明、真、偽、衝突(肯定・否定の両方が支持された状態)の4状態）は、ベルナップの4値論理（Belnap's 4-valued logic）の値集合に対応します。また、批判による推論規則の無効化は、ポロック（John L. Pollock）の undercutting defeater の概念に対応します。

## 🌟 主な特徴 & 形式意味論

1. **2ビット独立支持モデル**:
   - 各命題の状態を肯定支持ビット $b_+$ と否定支持ビット $b_-$ の直積として表現：
     - `00`: **`UNKNOWN`** (未証明・未支持)
     - `10`: **`TRUE`** (肯定支持のみ成立)
     - `01`: **`FALSE`** (否定支持のみ成立)
     - `11`: **`CONFLICT`** (肯定・否定の双方が支持された二律背反)
   - **前件否定の誤謬の根絶**: 前提不足は規則を「不発」にするのみで、結論の否定支持を自動生成しません。
   - **複数証明（別証明）の論理和的許容**: 一方の証明経路が遮断されても、別の独立した証明規則が残存していれば肯定支持が維持されます。

2. **推論意味論 (`diagnostic_monotone`)**:
   - **完全単調蓄積**: 推論途中で支持の撤回・消去を行いません。
   - **停止性の数学的保証**: 有限完備束上の単調写像となるため、Knaster–Tarski 定理により、いかなる入力に対しても有限ステップで一意な最小不動点へ確実に停止します。

## 🧩 他体系データを必要とするモジュールについて

本リポジトリは、スピノザ『エチカ』第1部の幾何学的論証に特化した**単独公開パッケージ**です。  
推論エンジン内には哲学体系間の比較や批判シナリオを扱う以下のモジュールが含まれていますが、これらは他体系データ（デカルト、ライプニッツ、カント批判等）を必要とするため、本単独版では機能が制限・非表示となります：

   - カント批判シナリオにおける各体系の耐震性カードを自動生成するモジュール（Web UIの「今回わかったこと」タブ）。
3. **`engine/comparative.py`**:
   - 複数体系間の概念・定理比較モジュール。

> **動作・テスト上の扱い**:  
> 本パッケージの Web UI では、他体系データを要求するタブ（「今回わかったこと」「耐震性ベンチマーク」）は非表示となっており、自律稼働する「幾何学グラフ」および「研究成果（命題11感度分析）」のみが提供されます。また、テストスイートにおける該当ベンチマークテスト（`test_07_benchmark_output_includes_required_metadata`）は明示的にスキップ（`skipped=1`）され、Spinoza 単独テスト全54件は外部依存なしに完全 PASS します。
